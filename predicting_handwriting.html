Predicting Handwriting

Leveraging Neural Networks to Predict Handwritten-Letters.

In this post, we will see how Machine Learning can be used to observe an image of a handwritten letter, and accurately predict which letter of the English alphabet the image depicts. There are various techniques within Machine Learning that can be used to achieve this objective, but this article will explore the use of K-Nearest Neighbors (KNN) and Convolutional Neural Networks (CNN).

But first, what is Machine Learning? Simply put, it's presenting pre-existing data, that shows both the inputs and outputs, to a machine and training it to identify patterns. Once trained, (we hope) the machines will be able to look at new data and predict an accurate outcome.

Data Sample & Preparation

A .csv file containing 372,450 rows (different handwritten letters), and 784 columns (known as 'features' or 'inputs' to our model) which contains the pixel value (0-255), and final column (known as 'target' or 'output') confirming the letter which the image represents, is used to train and test our models. Note that the images are in grayscale.

Data Transformations

  • Separate Inputs and Outputs. Since we want our models to predict the label using the pixel values, we create X (Features) and y (Target) variables to separate inputs, and outputs.
  • Assign 80% of data to train models. By training the models on 80% of the data, we can use the remaining 20% to evaluate how our model performs on unseen data.
  • Reshape. Presently, our data is flattened into one dimension. The models we will be building require that the data is in a two-dimensional image, i.e. a 28 pixel by 28 pixel image (28 * 28 = 784). By doing so we also preserve relationships between surrounding pixels.
  • One-Hot-Encode Target Variable. The label column contains values between 0 and 25, corresponding to the letters in the alphabet (A=0, B=1, C=2). In its present format, models we train may infer that C is greater than B, B greater than A. To resolve this we convert the labels into binary encoding using a method called One-Hot-Encoding.
